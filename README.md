# Edward Park · newstart

Edward Park의 프로필과 양봉 관리 아이디어를 소개하는 웹 프로젝트입니다.

- [공개 프로필](https://newstart.joripspace.run/profile)
- [프로필 정리 문서](edward.md)
- [GitHub 업로드 안내](GITHUB_UPLOAD.md)

## 주요 내용

- 프로필 소개와 관리자 비밀번호로 보호되는 프로필 정보 수정 기능
- 양봉 돌봄 시스템 아이디어와 판매 조건 소개
- 일시불 또는 최대 10개월 분할을 선택하는 모의 결제 화면

결제 화면은 체험용입니다. 실제 결제, 계약 체결, 권리 양도 및 자료 전달은 이 화면에서 이루어지지 않습니다.

## 프로젝트 구성

- `src/index.js`: Hono 기반 웹 페이지와 서버 로직
- `src/assets/`: 프로필 배경 이미지
- `migrations/`: 데이터베이스 스키마
- `edward.md`: 프로필 및 아이디어 정리

## 설치 및 빌드

Node.js 18 이상과 npm이 필요합니다. 프로젝트 폴더에서 실행합니다.

```bash
npm ci
npm run build
```

빌드 결과는 `dist/worker.js`에 생성됩니다. 실행에는 호환되는 Worker 환경이 필요합니다. 저장 및 관리자 인증 기능에는 데이터베이스와 관리자 비밀번호 설정이 필요하며, 조립스페이스 배포 환경의 바인딩을 사용합니다. 이 저장소에는 로컬 개발 서버 명령이 아직 마련되어 있지 않습니다.

## 보안 및 공개 범위

비밀번호, API 키, 토큰과 환경 설정 값은 Git에 포함하지 않습니다. `.gitignore`는 환경 파일, 의존성, 빌드 결과를 제외합니다. GitHub에 공개하기 전에는 프로필 문서와 작업 지침을 포함해 업로드할 내용을 검토해 주세요.
